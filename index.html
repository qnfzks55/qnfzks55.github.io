About

2017 ~ 현재

안녕하세요. 새로운 변화를 두려워하지 않고 더 나은 기술을 위해 도전하는 UX엔지니어 이명종 입니다. UX엔지니어 직무를 선택하면서 제가 왜 이 직업을 선택했는가 생각해 보았습니다.

저는 고등학교 시절 부터 한국산업인력공단에서 주관하는 전문 기술 직종의 기능을 연마하여 미래의 꿈을 키워나갈수 있는 웹디자인 및 개발 기술 분야 기능생 출신 이었습니다.

웹디자인기능생을 하면서 지방기능경기대회 동메달을 입상하여 전국기능경기대회에서도 동메달을 입상하고 본격적으로 웹 기술에 재미를 붙여왔습니다. 그 후 충청대 컴퓨터정보전공 졸업 후, 고려사이버대학교 디자인공학부에 편입하여 UI&UX 측면을 더욱 심도있게 공부하였습니다.

끝으로, IT 기술과 관련된 모든 대한민국 IT종사자 분들께 박수를 보냅니다.
감사합니다.

Skill

  • Semantic Markup
    플래시의 지지율이 떨어질 무렵 HTML5와 CSS3 의 등장으로 그 의미와 목적에 맞는 시맨틱한 마크업을 제공하여 최적화된 UI&UX 경험을 제공합니다.
  • 웹접근성 & 웹표준
    WAI-ARIA를 이용하여 UI행동이나 정보를 스크린 리더와 같은 보조 기술에 전달하여 시각/인지 장애인들에게 일반 사용자들과 동일하게 정보를 제공하고 행동을 유도함으로써 웹페이지 탐색을 돕는 최적화된 UX를 제공합니다.
  • Javascript
    객체 지향 프로그래밍을 지향하며 ES6를 활용하여 브라우저 최적화 및 성능개선을 위해 불필요 라이브러리 사용을 지양(프로젝트 특성에 따라서 jQuery도 활용가능) 합니다. 지금은 프론트엔드 UI 라이브러리 React.js를 학습중 입니다.
  • SCSS(SCSS)
    프로젝트의 특성에 맞게 믹스인과 함수를 적절하게 제작하여 활용 가능합니다. 예를 들면 반복해야 하는 클래스나 애니메이션 처리, 반응형웹 처리를 위한 기능을 제작합니다. 현재 모던 브라우저 환경에서의 CSS 기술을 좀더 깊이 학습 중 입니다.
  • Responsive Web
    다양화된 디바이스의 해상도와 환경에 최적화 하여 데스크탑, 태블릿, 모바일 디바이스에 맞춘 최신 트렌드인 반응형 및 적응형 웹사이트 제작이 가능합니다.
  • Photoshop & Figma
    웹디자인기능사 및 GTQ 그래픽기술자격 1급을 취득하여 기본적인 포토샵툴을 다룰 줄 알며, 최신 디자인툴인 Figma, Zeplin 등 현업 실무의 경험으로 디자이너와의 원활한 커뮤니케이션이 가능합니다.
  • Vue.js
    Vue 프로젝트 환경에서 UI개발과 실무위주의 Vue 프론트 개발을 메인으로 경험 하였습니다. 사내서비스의 추가기능이나 운영쪽 개발업무를 하였고 실무를 바탕으로 지속적으로 학습중에 있습니다.
  • React
    React 환경에서 UI개발을 주업무로 담당하였고 Storybook을 활용하여 Atomic Design Pattern으로 설계한 UI 컴포넌트들을 정의 하였습니다. 데이터 바인딩이 필요한 컴포넌트의 경우 비즈니스 로직을 구현하여 FE개발까지 부업무로 담당하였습니다.
